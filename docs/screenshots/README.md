When you add or replace a capture, crop out the browser toolbar and bookmarks, and keep video under about 10 MB so the repository stays small. To make the video play inside the README on GitHub, edit README.md on github.com and drag `demo.mp4` into the editor; GitHub hosts it and inserts a player link.
