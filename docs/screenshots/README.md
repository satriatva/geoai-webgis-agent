# Screenshots and demo video

Media used in the main README, captured from a local run in a maximized Chrome window (1920 px wide) and cropped to the page, 1917 × 869 px for the 1.1.0 captures.

| File | Shows |
| --- | --- |
| `buffer-query.png` | "Find hospitals within 2 km of Universitas Gadjah Mada" on Groq (`openai/gpt-oss-20b`): the search area, the results on the map and the answer in the dark theme |
| `result-popup.png` | The same answer after selecting a hospital in the result list: the map zooms in and opens its popup |
| `along-route.png` | "What cafes and fuel stations are on the way from Monas to Blok M?" on Google Gemini (`gemini-3.5-flash-lite`): the car route, its corridor, and the cafes and fuel stations along it in the dark theme (1.1.0) |
| `along-route-popup.png` | The same answer after selecting SPBU 34.102.06 in the result list: its popup shows the distance along the route and from the road (1.1.0) |
| `light-mode.png` | Start screen in the light theme, with Google Gemini (`gemini-3.5-flash-lite`) selected (1.1.0) |
| `dark-mode.png` | Start screen in the dark theme (1.1.0) |
| `../video/demo.mp4` | Recorded for 1.0.0, 74-second walkthrough: nearby search, distance, buffer with nearby search, and reverse geocoding of a selected point (1280 × 580, no audio) |

When you add or replace a capture, crop out the browser toolbar and bookmarks, and keep video under about 10 MB so the repository stays small. To make the video play inside the README on GitHub, edit README.md on github.com and drag `demo.mp4` into the editor; GitHub hosts it and inserts a player link.
